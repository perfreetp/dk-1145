# 摆摊区域维护系统

摆摊区域维护系统是一款面向城市管理人员的数字化工具，用于规范临时摆摊区域的管理。

## 功能特性

### 📊 统计看板
- 实时展示总摊位数、空闲摊位、待处理整改、待审核申请等核心指标
- 巡查趋势图表，查看每日巡查和违规情况
- 摊位状态分布饼图
- 即将到期提醒和逾期未整改警示

### 🗺️ 区域地图
- 交互式地图展示所有摆摊区域
- 支持区域边界绘制、编辑和删除
- 点击区域查看详细信息和摊位分布
- 摊位位置标记和弹窗信息展示

### 🏪 摊位列表
- 摊位信息的增删改查
- 多维度筛选：按状态、区域、品类、搜索
- 展示摊位编号、状态、经营时段、负责人、到期日期
- 状态标签直观区分空闲、已占用、维护中

### ✅ 申请审核
- 待审核、已通过、已拒绝分类展示
- 查看申请人详细信息和证件照片
- 审核通过后分配空闲摊位
- 拒绝时填写拒绝原因

### 🔍 巡查记录
- 记录巡查问题（占道、卫生、噪音、其他）
- 设置问题严重程度和整改期限
- 上传问题照片
- 跟踪整改进度

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **路由**: React Router 6
- **状态管理**: Zustand 5
- **UI 组件库**: Ant Design 5
- **样式**: Tailwind CSS 3
- **地图**: Leaflet + React-Leaflet 4
- **图表**: Recharts 2
- **图标**: Lucide React

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173 查看应用。

### 构建生产版本

```bash
npm run build
```

### 类型检查

```bash
npm run check
```

## 项目结构

```
src/
├── components/          # 可复用组件
│   ├── common/         # 通用组件（Card、Badge、Empty）
│   └── layout/         # 布局组件
├── pages/              # 页面组件
│   ├── Dashboard/      # 统计看板
│   ├── Map/            # 区域地图
│   ├── Vendors/        # 摊位列表
│   ├── Applications/   # 申请审核
│   └── Inspections/    # 巡查记录
├── stores/             # Zustand 状态仓库
├── types/              # TypeScript 类型定义
├── data/               # Mock 数据
└── App.tsx             # 应用入口
```

## 数据说明

系统使用 LocalStorage 进行数据持久化，包含以下模块的示例数据：

- 5 个摆摊区域
- 50 个摊位
- 20 条申请记录
- 100 条巡查记录
